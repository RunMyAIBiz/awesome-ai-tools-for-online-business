# Contributing

Thanks for helping keep this list useful!

- Add **one tool per pull request**, in the best-fitting category.
- Format: `- [Name](official-url) - One-line description ending in a period. <pricing emoji>`
- Pricing key: 🆓 free plan or tier · 💲 paid plans · 🧾 pay per use or per transaction.
- **Official links only.** No affiliate, referral, tracking or shortened links.
- The tool must be live, maintained, and useful to non-programmers building or running an online business.
- Keep descriptions factual: no superlatives, hype or income claims.
- Disclose in the PR if you work for or are affiliated with the tool.
- Report dead links or outdated pricing notes by opening an issue.
